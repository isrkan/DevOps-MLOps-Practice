# Linux Guide

Linux powers most of the world's servers, cloud infrastructure, containers, and developer tools. Whether we are deploying applications to AWS, building CI/CD pipelines, training machine learning models, or simply working as a backend developer - we will encounter Linux constantly. Knowing it well is one of the highest-leverage skills in modern tech.

This section is a practical, hands-on learning path that takes us from our very first terminal command to writing shell scripts, managing services, hardening servers, and processing data with command-line tools.

## Getting started
Before working through the guides, we need Linux running on our machine. There are two common ways to do this on Windows:
- **WSL (Windows Subsystem for Linux)** - runs Ubuntu directly inside Windows with minimal overhead. Recommended for most learners.
- **VirtualBox** - runs a full Ubuntu desktop as a virtual machine. Better if we want a complete graphical Linux environment.

Both options are covered in the setup guides in this directory.

We will be comfortable working in a Linux environment - navigating the filesystem, managing users and permissions, writing automation scripts, configuring services, troubleshooting problems, and using the command-line tools that are standard across DevOps workflows.
